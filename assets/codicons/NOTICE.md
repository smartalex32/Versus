# Microsoft VS Code Codicons attribution

`codicon.ttf` is the unmodified font from the official
[`@vscode/codicons` 0.0.46-24](https://www.npmjs.com/package/@vscode/codicons/v/0.0.46-24)
package, published by Microsoft. It is used only for the five folder Find and
Replace controls in Versus.

The corresponding official vector sources are `case-sensitive.svg`,
`whole-word.svg`, `regex.svg`, `replace.svg`, and `replace-all.svg` from
[`microsoft/vscode-codicons`](https://github.com/microsoft/vscode-codicons),
revision `8853e0b1b0e2058b099fde515d5f1f478db2f8e1` (retrieved 2026-10-14).
The font itself has not been modified.
